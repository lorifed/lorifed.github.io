Overview

Il problema

Creare contenuti è lento

Gestire un profilo Instagram professionale per un'agenzia richiede ore ogni settimana: ideazione, copywriting, design, voiceover, editing, scheduling. Moltiplica per 3 aree (Meta Ads, Siti Web, AI) e diventa insostenibile per un one-man studio.

La soluzione: una pipeline AI

Un sistema che prende in input un briefing testuale + foto reference e restituisce contenuti finiti: reel animati con voiceover, caroselli con design ricco, caption bilingue e posting automatico. Tu compili le schede, il sistema fa tutto il resto.

Pipeline

Come funziona, passo per passo

01

Piano bisettimanale

10 slot fissi ogni 2 settimane: 6 reel + 4 caroselli, distribuiti su 3 aree (Meta Ads, Siti Web, AI) e 3 fasi funnel (TOFU, MOFU, BOFU). Il piano è strutturale — si compila, non si pensa.

Content MatrixTOFU/MOFU/BOFU
02

Briefing con reference

Ogni slot ha una cartella con una scheda da compilare: angolo suggerito, esempio di riferimento, note. Foto reference di altri creator vengono caricate nella cartella — l'AI le analizza con la vision API e ne replica lo stile visivo.

Scheda compilabileVision API
03

Generazione reel (Claude Code + Remotion)

Claude Code legge la scheda e scrive componenti React personalizzati per ogni video: animazioni fluide, mockup dashboard, tipografia bold, transizioni clip-path. Remotion renderizza il video finale a 1080×1920 30fps.

Claude CodeRemotionReactVibe Motion
04

Voiceover automatico

Lo script parlato viene generato insieme al video. ElevenLabs sintetizza la voce con il modello multilingue v2 e Claude sincronizza le scene con l'audio — tutto in automatico.

ElevenLabsMultilingual v2
05

Generazione caroselli (Claude API + Puppeteer)

Per i caroselli, Claude vede le foto reference e genera HTML ricco per ogni slide — code block, card con bordi, terminal mockup, layout multi-sezione. Puppeteer renderizza ogni slide a 1080×1350 (4:5). La CTA finale è fissa e garantita.

Claude VisionPuppeteerHTML slides
06

Posting automatico su Instagram

I contenuti vengono caricati su Cloudinary (URL pubblico), poi pubblicati via Instagram Graph API. Un cron job posta un contenuto al giorno alle 21:00, dal lunedì al venerdì. Il token è long-lived (60 giorni) con rinnovo gestito.

Architettura

Come è costruito

⚡

Due engine, un'interfaccia

I reel passano per Claude Code + Remotion (video React custom). I caroselli usano Claude API + Puppeteer (HTML ricco → screenshot). Entrambi leggono le stesse schede dalla stessa cartella.

📁

Batch folder system

10 cartelle numerate con scheda + foto reference. Il nome della cartella codifica area, formato e funnel (es. 04_META-ADS_Carosello_MOFU). Zero ambiguità.

👁

Reference visive con Vision

Le foto reference vengono inviate a Claude come immagini base64. Claude analizza lo stile visivo (layout, densità, elementi grafici) e lo replica nelle slide generate — non solo il testo, ma il design.

🔄

Posting queue + cron

La queue JSON traccia cosa è stato postato e cosa no. Il cron job controlla ogni giorno, posta il prossimo item, e segna come fatto. Se qualcosa fallisce, riprova il giorno dopo.

Dettaglio tecnico chiave

I caroselli usano un formato con separatori ---SLIDE--- invece di JSON, perché l'HTML dentro il JSON rompeva il parsing. Claude scrive HTML libero per ogni slide — code block, card terminal, tabelle stilizzate — e Puppeteer lo renderizza a 1080×1350. La CTA finale è sempre generata da un template fisso per evitare slide nere.

Content strategy

Matrice contenuti

3 aree × 3 funnel

Ogni batch copre Meta Ads, Siti Web e AI — attraverso le 3 fasi del funnel: TOFU (awareness, hook largo), MOFU (autorità, metodo e framework), BOFU (conversione, case study con numeri reali). La distribuzione è bilanciata per design.

6 reel + 4 caroselli

I reel catturano attenzione con motion graphics e voiceover. I caroselli costruiscono autorità con contenuto strutturato e denso. Il mix è calibrato su ciò che funziona su Instagram nel 2026: video per reach, slide per salvataggi.
