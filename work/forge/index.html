The problem

Running a studio across six brands meant twelve subscriptions, context scattered across tools, and no single place where the operating knowledge lived.

What we built

  1. 01

    A local-first desktop shell so client data and brand knowledge never leave the machine.

  2. 02

    Six departmental agents — research, copy, creative, media buying, reporting, ops — sharing one persistent memory layer.

  3. 03

    A Research → Copy → Training pipeline that turns raw market signal into approved, on-brand output.

  4. 04

    Headless browser workers for scraping, competitor tracking and publishing.

Outcome

FORGE now runs the day-to-day of 21STUDIO. It became the blueprint for the hosted product.
