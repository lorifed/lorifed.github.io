Overview

Il problema
Troppi tool, zero contesto brand

Gestire più brand con strumenti separati significa perdere contesto ogni volta. Il brief va riscritto, le note vanno recuperate, la storia del brand si azzera ad ogni sessione.

La soluzione
Un OS che ricorda tutto

FORGE centralizza memoria brand, agenti AI specializzati e pipeline operative in un'unica app nativa macOS. Il contesto di ogni brand viene iniettato automaticamente in ogni sessione senza riscrivere nulla.

Agenti

6 agent, una sola interfaccia

01
Research Agent

Scraping headless via Puppeteer su Facebook Ads Library. Raccoglie ads attive dei competitor in real-time, con analisi AI di hook, pattern creativi e CTA dominanti.

Puppeteer · Claude API
02
Copy Agent

Genera Meta Ad copy — Hook, Body, CTA — analizzando competitor scrappati e brand context. Output in varianti con quality rating 1–5 per raccogliere training data.

Claude API · JSONL training
03
Neuro Agent

Analisi neuromarketing di immagini e video per Meta Ads. Identifica musica, patterns visivi, hook e genera raccomandazioni creative basate su psicologia del consumatore.

Vision API · Audio analysis
04
Marketing Agent

Chat Claude con contesto brand iniettato automaticamente dalla memoria. Strategia contenuto, caption, copy email — senza dover rispiegare il brand ogni volta.

Claude API · Brand memory
05
Meta Ads Agent

Specializzato in campagne CBO/ABO, target audience e ottimizzazione budget. Contestualizzato sulle note operative del brand attivo.

Claude API · Ads strategy
06
Knowledge Agent

ChromaDB + Python per interrogare lo storico completo delle sessioni. Recupera insight e report precedenti tramite query in linguaggio naturale.

ChromaDB · RAG · Python

Architettura

Local-first, zero dipendenze cloud

⚡
Electron + Express server locale

App nativa macOS. Server Express interno (porta 3847) — tutto comunica in localhost, nessun dato passa per server esterni.

◎
Brand memory persistente su filesystem

Ogni brand ha memory.json, storico sessioni e asset. Il contesto viene iniettato automaticamente negli agent.

◈
Pipeline Research → Copy → Training

Lo scraping competitor alimenta il Copy Agent. I rating producono automaticamente training_data.jsonl per fine-tuning futuro.

◉
ChromaDB + RAG per la memoria a lungo termine

Knowledge Agent usa ChromaDB + sentence-transformers per cercare nelle sessioni passate con query in linguaggio naturale.

Dettaglio tecnico chiave

La pipeline Research → Copy → Quality Rating genera automaticamente un dataset JSONL con le coppie brand_context/copy/score. L'obiettivo è accumulare esempi di alta qualità per fine-tunare un modello sul proprio stile di copywriting per ogni brand.

Flusso operativo

Come si usa nella pratica

01
Seleziona brand

Scegli il brand dal switcher. Il contesto, le note e i competitor si caricano automaticamente.

02
Scraping competitor

Research Agent raccoglie le ads attive su Ads Library. Puppeteer gira in headless, nessuna configurazione.

03
Analisi AI + Copy

Claude analizza i pattern competitor e genera varianti di copy. Il Neuro Agent valuta le creative visive.

04
Rating e memoria

Valuta il copy 1–5. Il dato va nel training set. La sessione entra nello storico brand automaticamente.
