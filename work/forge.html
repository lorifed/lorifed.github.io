Overview

Il problema
Troppi tool, zero contesto brand

Gestire più brand con strumenti separati significa perdere contesto ogni volta che si apre un nuovo chat, un nuovo tab, un nuovo SaaS. Il brief va riscritto, le note vanno recuperate, la storia del brand si azzera ad ogni sessione.

La soluzione
Un OS che ricorda tutto

FORGE centralizza memoria brand, agenti AI specializzati e pipeline operative in un'unica app nativa macOS. Il contesto di ogni brand viene iniettato automaticamente in ogni sessione — Research, Copy, Marketing, Ads — senza riscrivere nulla.

Agenti

6 agent, una sola interfaccia

01
Research Agent

Scraping headless via Puppeteer su Facebook Ads Library. Raccoglie e visualizza le ads attive dei competitor in real-time, con analisi AI automatica degli hook, pattern creativi e CTA dominanti.

Puppeteer · Claude API
02
Copy Agent

Genera Meta Ad copy — Hook, Body, CTA — analizzando i competitor già scrappati e il contesto brand salvato. Output in varianti con sistema di quality rating 1–5 per raccogliere training data.

Claude API · JSONL training
03
Neuro Agent

Analisi neuromarketing di immagini e video per Meta Ads. Identifica musica, patterns visivi, hook visivi e genera raccomandazioni creative basate su principi di psicologia del consumatore.

Vision API · Audio analysis
04
Marketing Agent

Chat Claude con contesto brand iniettato automaticamente dalla memoria. Strategia di contenuto, caption, copy email, posizionamento — senza dover rispiegare il brand ogni volta.

Claude API · Brand memory
05
Meta Ads Agent

Specializzato in struttura campagne CBO/ABO, definizione target audience, ottimizzazione budget e scaling. Contestualizzato sulle note operative e i dati del brand attivo.

Claude API · Ads strategy
06
Knowledge Agent

ChromaDB + Python per interrogare lo storico completo delle sessioni passate. Recupera insight, report e decisioni precedenti tramite query in linguaggio naturale.

ChromaDB · RAG · Python

Architettura

Local-first, zero dipendenze cloud

⚡
Electron + Express server locale

L'app gira come processo nativo macOS. Un server Express interno (porta 3847) espone le API agli agenti — tutto comunica in localhost, nessun dato passa per server esterni.

◎
Brand memory persistente su filesystem

Ogni brand ha una cartella con memory.json, storico sessioni e asset. Il contesto sopravvive tra sessioni e viene iniettato automaticamente negli agent.

◈
Pipeline Research → Copy → Training

Lo scraping competitor alimenta il Copy Agent. I rating di qualità sul copy generato producono automaticamente file training_data.jsonl per fine-tuning futuro.

◉
ChromaDB + RAG per la memoria a lungo termine

Il Knowledge Agent usa ChromaDB con sentence-transformers per cercare nelle sessioni passate. Query in linguaggio naturale, risultati contestuali.

Dettaglio tecnico chiave

La pipeline Research → Copy → Quality Rating genera automaticamente un dataset JSONL con le coppie brand_context/copy/score. L'obiettivo è accumulare abbastanza esempi di alta qualità per fine-tunare un modello sul proprio stile di copywriting specifico per ogni brand.

Flusso operativo

Come si usa nella pratica

01
Seleziona brand

Scegli il brand dal switcher nella sidebar. Il contesto, le note e i competitor si caricano automaticamente.

02
Scraping competitor

Research Agent raccoglie le ads attive su Facebook Ads Library. Puppeteer gira in headless, nessuna configurazione.

03
Analisi AI + Copy

Claude analizza i pattern competitor e genera varianti di copy pronte. Il Neuro Agent valuta le creative visive.

04
Rating e memoria

Valuta il copy 1–5. Il dato viene salvato nel training set. La sessione entra nello storico brand automaticamente.
